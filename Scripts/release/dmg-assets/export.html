Install QuotAI
1 Drag QuotAI → Applications
2 Open QuotAI from Applications
Menu bar — no Dock icon by default
? Keychain (optional)
QuotAI stores API keys in the macOS Keychain. Expect this after each new install / version — not a Gatekeeper block.
Enter system password and Click Always Allow
? If blocked (optional)
QuotAI isn’t Apple-notarized yet, so Gatekeeper may show “Not Opened”. That’s macOS protecting you — skip this if the app launches fine.
  1. Click Done (not Move to Bin)
  2. System Settings → Privacy & Security
  3. Click Open Anyway → confirm → Touch ID / password
