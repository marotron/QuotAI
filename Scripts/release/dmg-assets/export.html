Install QuotAI
1 Drag QuotAI → Applications
2 Open QuotAI
3 Keychain
Enter system password and Click Always Allow
QuotAI stores API keys in the macOS Keychain. Expect this after each new install / version. Not a Gatekeeper block — choose Always Allow.
If blocked (optional)
4 Done
Click Done
5 Settings
6 Settings
Click Open Anyway
7 Confirm
Click Open Anyway
8 Unlock
Use Touch ID / password
QuotAI isn’t Apple-notarized yet, so Gatekeeper may block the first open (“Not Opened”). That’s macOS protecting you — not QuotAI asking for permission. Open Privacy & Security → Open Anyway once; skip if the app launches fine.
